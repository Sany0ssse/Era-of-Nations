# Technical support

Era of Nations is developed in [Sany0ssse/Era-of-Nations](https://github.com/Sany0ssse/Era-of-Nations). Report reproducible issues there with the game version, mod revision, enabled playset, steps, and relevant error-log excerpts.

Use a dedicated playset with only Era of Nations. Read the [setup guide](development/SETUP.md) and [current validation status](development/STATUS.md) before troubleshooting compatibility.

The [inherited troubleshooting guide](player-tutorials/troubleshooting-guide.md) is a reference for the source baseline; its older version-specific advice is not a current compatibility guarantee.

This project has no published Steam Workshop build yet.
