# Git authentication for Era of Nations

The project repository is [Sany0ssse/Era-of-Nations](https://github.com/Sany0ssse/Era-of-Nations). Verify that your Git remote points to that repository and that the signed-in GitHub account has access before pushing.

Use your existing Git credential manager or GitHub CLI authentication. Do not place passwords or tokens in tracked files, remote URLs, screenshots, or logs.

For the local checkout and current repository state, see [setup](../development/SETUP.md).
