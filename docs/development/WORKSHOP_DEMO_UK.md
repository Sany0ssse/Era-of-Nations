# Era of Nations — демка для спільного тестування

Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=3814861738

Збірка: **0.1.0-demo.3**, оновлена 2026-10-13.
Build: `0.1.0-demo.3-20261013-6725dc23d26b`.
SHA-256 знімка ігрових джерел: `6725dc23d26b5470f4bc26af191eea1fd6edb6b0e362c0d8f35269691b67ee3f`.
Назва в лаунчері: **Era of Nations - Multiplayer Demo**.
Самостійний мод для HOI4 `1.19.x`; окремі Workshop-версії основи не потрібні.
Пакет — приблизно 7,4 ГБ. Чинний Workshop-предмет збережено, видимість — загальнодоступна.

## Як розпочати з другом

1. Підпишіться на демку й дочекайтеся завершення оновлення у завантаженнях Steam.
2. Повністю перезапустіть лаунчер і гру, щоб вони прочитали нові файли.
3. Увімкніть лише **Era of Nations - Multiplayer Demo**. Локальну Era of Nations і окремі Millennium Dawn / Damaged Continuum вимкніть.
4. Звірте повну версію гри та контрольну суму в головному меню на обох ПК.
5. Почніть нову тестову кампанію, оберіть різні країни; друг приєднується до лобі хоста.

## Стан перевірки

Steam повернув успішний результат оновлення наявного предмета 2026-10-13.
Нативний Steam API та незалежний анонімний Steam Web API підтвердили той самий
ID, власника й HOI4 AppID, новий англійський опис, Build і час оновлення.
Назву, видимість, теги та основне прев'ю збережено.

Незалежно звірено всі 68,620 вихідних і 68,623
пакетних файлів за SHA-256. Staging descriptor відрізняється тільки назвою/версією
демки та ID цього Workshop-предмета. Авторські повідомлення й чотири музичні
кредити збережено. `.git`, `.local`, розробницькі інструменти, резервні копії
та дескриптор із локальним абсолютним шляхом у пакет не потрапили.

14 груп перевірок джерел/моделей пройшли; дипломатичний агрегат містить 28 звітів.
Це не підтвердження довгої кампанії, сумісності всіх старих збережень чи
синхронізації двох клієнтів. Загальне підвищення FPS не підтверджено.
Користувацькі збереження й сторонні набори модів не змінювалися.

Для повідомлення про помилку вкажіть версію/контрольну суму обох гравців,
країни, дату кампанії, дію та результат або повідомлення desync.
