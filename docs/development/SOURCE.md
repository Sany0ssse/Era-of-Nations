# Source and attribution

Era of Nations is a standalone development fork built from a user-supplied
Millennium: Damaged Continuum / Director's Cut development snapshot, itself
containing Millennium Dawn material. The inherited gameplay and assets are
upstream work; the initial Era of Nations changes establish the project identity
and local development setup.

## Imported snapshot

- Archive: `mdredux-main.zip` (the original is preserved outside the repository).
- SHA-256: `6aba5fd7871b1c8966c307d4b666f8e0e2d8da355cdb10e002a3988b1e59d71c`.
- Imported on 2026-10-05: 74,465 files, 7,602,562,427 uncompressed bytes.
- Archive wrapper directory `mdredux-main/` was removed during extraction.
- Source descriptor identified Workshop item `3721160655` and HOI4 `1.19.*`.
- No separate LICENSE or COPYING file was present in the supplied archive.
  This project does not assign a new license to inherited material or claim that
  absence of a license is permission to redistribute it.

import receipt and original branding backups are in the ignored `.local/`
directory, outside the published Git tree.

New Era of Nations branding does not change ownership of the inherited work.
Steam Workshop publication is not part of this initial setup.
