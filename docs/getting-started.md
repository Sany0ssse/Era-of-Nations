# Getting started with Era of Nations

Use the [local setup guide](development/SETUP.md) to register the checkout with the Hearts of Iron IV launcher. Select a dedicated playset containing only Era of Nations.

This standalone fork includes the inherited gameplay baseline. It does not require enabling the original mod alongside it. Save a new test campaign separately from existing campaigns.

The initial build is a development version. Read [validation status](development/STATUS.md) for the tested game version and observed results. Steam Workshop publication is reserved for a later stage.

For inherited mechanics, start with the [economy tutorial](player-tutorials/economy-tutorial.md), [European Union tutorial](player-tutorials/eu-tutorial.md), and [guides](guides.md). These guides are source material and may refer to mechanics that still need testing in this fork.
