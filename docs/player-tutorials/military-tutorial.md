У грі відкрийте **Решения → Помощь по составу дивизий → Открыть руководство
по дивизиям**. Це безкоштовна довідка про склад, підтримку та забезпечення.

Стовпці конструктора — полки, а ряди — ячейки їхньої організаційної схеми.
Верхній ряд не є першою лінією бою. Важливі склад, характеристики,
укомплектованість, підготовка та забезпечення.

До відповідного полку зі щонайменше трьома сумісними лінійними батальйонами
можна додати легку або моторизовану полкову артилерійську батарею. Їй потрібні
люди, оруддя і засоби управління; моторизованій — також машини й пальне.
