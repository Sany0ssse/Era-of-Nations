# Era of Nations FAQ

## What is this build?

A standalone development fork that starts from inherited modern era gameplay. The initial changes establish branding, the repository, and local installation. See [source and attribution](development/SOURCE.md).

## Do I enable the original mod as well?

Enable only Era of Nations in a dedicated playset. The checkout includes its gameplay baseline.

## Which game version is supported?

The source descriptor’s declared version is retained until game testing justifies a change. See [validation status](development/STATUS.md) for the declared version, installed version, and actual results.

## Is it on Steam Workshop?

Workshop publication is reserved for a later stage of development.

## Are old campaigns compatible?

Compatibility has not been established. Start a separate test campaign and preserve existing saves.

## Where do I report an issue?

Use the [development repository](https://github.com/Sany0ssse/Era-of-Nations) with reproduction steps and the game version, project revision, and enabled playset.

## Who created the inherited content?

The [source record](development/SOURCE.md), [authors list](misc/authors.md), and original music credit files retain the source attribution.
