# Install Era of Nations locally

The development checkout contains the playable mod files. Register an external `.mod` file in your Hearts of Iron IV user-data `mod` directory and point its `path` at this checkout. The descriptor name is **Era of Nations**.

Use [the local setup guide](docs/development/SETUP.md) for this computer’s actual paths and launcher steps. Enable only Era of Nations in a dedicated playset; this checkout includes its inherited gameplay data.

The initial development build is not a Steam Workshop release. Consult [validation status](docs/development/STATUS.md) before relying on a game version or campaign result.
