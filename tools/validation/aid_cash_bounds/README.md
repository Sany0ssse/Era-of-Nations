# Перевірка меж казни в економічній допомозі

`python -B tools/validation/aid_cash_bounds/test_bounds.py` виконує актуальні
тригери з двома новими перевірками: верхня межа казни донора перед списанням
та нижня межа казни отримувача перед зарахуванням. Старий helper завжди
обмежує казну діапазоном ±1 000 000; позамежний вхід раніше змінював сторонні
кошти разом із грантом. Номінали 5/15/35, резерв і повернення не змінено.

`byte_compat.py` застосовується лише до історичних побайтових тверджень.
Він перевіряє SHA всього актуального файлу, точну наявність двох нових островів,
видаляє лише два додані рядки й перевіряє SHA попереднього файла. Старі
baseline, журнали `aid_flag_scope` і їхні SHA залишаються незмінними.
Поведінкові перевірки продовжують читати актуальне дерево з новими guards.
Жодного глобального підмінювання читання файлів немає. Зміна будь-яких інших
байтів або неповна зміна відхиляється. Це джерельні перевірки, не кампанія HOI4.
