# Завершення життєвого циклу консультацій

Запуск: `python -B tools/validation/consultation_lifecycle_completion/run_checks.py`.
Команда друкує один JSON зі станом перевірок, сценаріями, відтворенням старих
помилок, навмисними регресіями та SHA256 фактично прочитаного коду.

Після прострочення живої узгодженої пари зберігаються ролі, партнер, тема та
резервація. Обидві сторони отримують `eon_consultation_expired`. Надсилання,
прийняття і відкликання стають недоступними; відновлення самих часових прапорців
не поновлює прострочену заявку. Оригінальне вікно порядку денного можна закрити;
оригінальна відповідь завершить заявку без угоди чи нової плати, повідомить про
прострочення і звільнить відповідну пару. Для надісланої заявки зберігається
наявна 90-денна затримка; ненадісланий порядок денний її не створює.

Загиблі, анексовані або пошкоджені записи й надалі закриваються з постійною
забороною повторного використання саме цієї пари: старе вікно не має окремого
ідентифікатора покоління. Уже наявні історичні заборони не видаляються, адже їхнє
походження неможливо надійно відрізнити. Цей пакет не відновлює такі старі записи.

Модель виконує поточні AST дій, варіантів відповіді та helpers. Вона окремо
перевіряє грошові змінні, інші угоди, політичну вартість, точного партнера, тему,
повторну відповідь, відмову, відкликання, війну та анексію. Перевірка FLAGS
відповідає native24/29: суфікс зі скалярною назвою не підставляє країну; потрібна
реальна країна у контексті `@PREV`/`@FROM`. Скалярні VARIABLES мають інші правила.
Тимчасові значення спільні в межах виклику, а scoped scalar read читає постійну
змінну відповідної країни, як установлено native10.

`_source_guard.restore_before(relative_path, raw=None)` перевіряє повний SHA
поточних байтів, повертає тільки десять дозволених блоків до початкового стану та
звіряє SHA результату. Це інверсія для перевірки збереження джерела. Виконання
сценаріїв завжди використовує поточний код. Старий код відтворює 13 збоїв;
13 окремих навмисних регресій відхиляються поведінковими перевірками.

76 сценаріїв проходять: 34 сценарії життєвого циклу та 42 меж джерела/адаптера.
Це перевірки скриптів. Прострочення задається явно; виконання варіанта відповіді
не доводить споживання справжнього вікна рушієм. Нативні таймери, поведінка ШІ,
видимість інтерфейсу, збереження та мультиплеєр тут не моделюються. Старий пакет07
має історичний адаптер для інших фінансових helpers і не замінює ці перевірки.
