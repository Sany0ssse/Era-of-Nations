# Перевірка внутрішніх тестових інструментів

Поточна перевірка джерел і країнових змін:

```powershell
python -B tools/validation/private_debug_panel/test_panel.py
```

Вона читає фактичні GUI, callback-и та ефекти. Перевіряє потрібну країну,
вимкнений доступ, AI, повторний виклик після закриття й допустимі кількості.
Історичний `test_hotkey.py` збережено без змін; його закритий початковий
обсяг не є перевіркою поточної версії після наступних пакетів.

Модель не доводить нативну обробку клавіш або синхронізацію двох клієнтів.
Інструкції внутрішнього використання зберігаються лише локально в `.local/`.
