# Consultation source checks

Run `python -B tools/validation/diplomacy_package_07/run_checks.py` from the checkout.

The runner counts all 4786 previous diplomacy scenarios plus 156 new actual-source scenarios: `symbolic_scenarios = 4942`. The consultation file reports `total_cases = 160`, split into `actual_source_scenarios = 156` and `adapter_semantics_cases = 4`. The runner exposes these four checks separately as `consultation_adapter_semantics_checks`; independent source assertions are also separate and are not added to the behavior count.

The consultation adapter loads the ordered interpreter definitions without executing or recounting the old scenario loops. Unknown effects and triggers fail closed. Its four native `NOT`/explicit-`AND` truth-table checks distinguish native child NOR from negation of an explicit `AND` (NAND). This adapter correction is local to package 07.

The behavior tests execute the installed native actions, consultation helpers, event option guards and effects, AI modifiers and on-action bodies. They exercise literal trade, energy and financial topics; an exact 10 political-power payment including fractional affordability; fresh action/click guards; crossed and unrelated pairs; cancellation, withdrawal, acceptance and refusal; explicit draft/request/channel expiry; wrong-country and wrong-topic callbacks; annex and subject-integration roles; corrupt mirrored records; and static result acknowledgements. Invitation-description selection is evaluated against the literal event topic and matching current pair.

Native country facts are supplied explicitly: existence, human/AI control, faction, opinion, war, treasury, factories, GDP, leaders, influence-array membership and timer flags. Declared timer durations are checked from the actual source. Expiry tests remove the corresponding country flag as an explicit fixture; the adapter does not simulate the engine clock or event-delivery schedule.

Forced daily cleanup of a missing partner or structurally invalid record always retires the known affected pair permanently, even when one record appears active. Forced expiry of an unconsumed agenda or invitation also retires its pair. That conservative tombstone prevents a delayed original callback from attaching to a new same-pair request after expiry or country revival; other partners remain usable. A normally consumed cancellation or expired reply can release its reservation without retirement. A consistent agreed channel can close, expire or be cleaned by an annex hook without retirement because its original recipient reply has already been consumed. Arbitrarily duplicating an already consumed modal into a later same-pair session is outside this bounded native callback model.

Financial talks grant no aid automatically. The follow-up action evaluates the actual existing aid eligibility helper and opens its ordinary separate draft. Tests retain the original influence, GDP, factory, Eritrean national, treasury, cooldown and pair restrictions, then execute a separate 5-billion escrow/acceptance cycle from the existing aid event source. Ending talks preserves the independent grant, debt, refund ledger, treaties and energy records. External influence/opinion macro calls are recorded, while aid cash uses the actual treasury helper; no assumption of native economic recomputation is made.

This establishes bounded ordered source behavior and unchanged-source boundaries. It does not prove native compilation, callback ordering, country-value serialization, real timer expiry, GUI layout, save/load behavior, campaign balance or a playable campaign. No game process, save or Workshop file is changed by these checks.
