# Package 28: current-source framework negotiations

Run from the checkout root:

```powershell
python tools/validation/diplomacy_package_28/run_checks.py
```

`test_lifecycle.py` executes the actual current action, targeted decision,
scripted trigger, scripted effect and lifecycle AST. The fail-closed adapter
extends package 26's country scope, scoped key, flag expiry and array semantics.
Unknown commands fail. It covers sender/receiver frames, multi-partner and
multi-type requests, reviewed epochs, exact clauses, three counter rounds,
75-PP fees including 48 fractional-affordability cases across all four charged
operations, expiry, refusal, withdrawal, new and legacy termination, vanished
parties, national and allied constraints, AI decision weights and preserved
project/cash/delivery state. Retired native callbacks are executed against
current new requests and agreements to prove their namespace separation.

`test_source.py` pins `f2832b6bfd980066163d0a69a6306169c992c5d7` and proves that
the legacy native action file differs only inside the four explicitly retired
action blocks. Existing trade/investment pair helpers retain their exact bytes.
It also checks native identity uniqueness, unchanged sender AI desire,
informational event options, actual targeted UI frames, final effect guards,
UTF-8 BOM/line endings and matching complete English/Russian localisation.
Actual dynamic status selector AST is exercised for recorded 90/180-day
clauses, current round terms, mutual termination, obsolete requests, no request
and a different selected partner.

The runner requires both suites to observe identical current source hashes.
The JSON durable round trip is an adapter fixture, **not an HOI4 save/load**.
Native AI scheduling, button rendering, treaty execution in a real campaign,
multiplayer synchronization and performance remain separate acceptance work.
The inherited influence and Singapore recalculation macros are witnessed with
actual call scope/arguments; their internal economic effects are not simulated.

Native10 in the installed engine confirmed that execution temporaries are
shared across country scopes and cannot be read as `PREV.temp_name`. The
adapter now uses shared execution storage, discards it at public effect
entry/round trips, and resolves explicit country-prefixed reads only from
persistent variables. Ten primitive assertions and actual-source guards
protect this semantics. The core source replaces 50 unreadable scoped temp
references while preserving persistent paired records. Current suites pass
684 lifecycle assertions and 389 source assertions; these counts are not
native campaign test counts.
