# Поточні перевірки пакета 26

```powershell
python -B tools\validation\diplomacy_package_26\run_checks.py
```

`test_relations.py` виконує поточні AST рішень, умов і ефектів пакета. Це строгий виконавець вузького набору country scopes, scoped flags/variables, масивів і строків; невідомі команди зупиняють перевірку. Тести проходять усі `allowed`, `target_root_trigger`, `target_trigger`, `visible`, `available` та фактичний `complete_effect`. Примусові виклики окремо доводять повторний guard під час виконання.

Покрито двосторонні відносини; окремі напрями місій; згоду, відмову, відкликання і повторне звернення; строки; зміну національної політики; недостатні поточні ресурси; агреман і окрему активацію грамот; зміну класу; відкликання, persona non grata, закриття і розрив; незалежні партнерські канали; чергу повторних виїздів та її підтвердження; анексію й війну. Довгий таймер не «доводить» виїзд. Виконавець зберігає і відновлює свою JSON-модель без тимчасових змінних; це не native `.hoi4` save/load.

`test_source.py` перевіряє десять game-файлів, UTF-8/BOM/CRLF, граф власних helper ID, 20 рішень, три суто інформаційні події, парні guards, узгодженість масивів виїзду, мовних ключів і зрозумілих статусів. Постійні мутації обмежені власними полями, коштами, політичними очками й точним `no_diplomatic_ties`; глобального обходу пар країн або примусового миру немає.

`test_legacy_registry.py` перевіряє всі 38 чинних напрямлених змін `no_diplomatic_ties`: 34 у старих історіях, фокусах, подіях, рішенні та національному відновленні; чотири у нових загальних розриві й відновленні. Два старі приклади в `effect_tooltip` залишаються без виконуваних записів. Для десяти попередніх файлів перевіряється точна побайтова різниця з комітом `c1420b108dee2d129018951c9ba73c1f6bfc4360`: дозволені тільки відповідні записи пари та одна заміна старої загальної перевірки на точну. Модель виконує реальні фрагменти ефектів в обох напрямах і перевіряє всі інші пари. Окремо перевіряються пороги грошей/політичних очок, відмова від недопустимого нативного синтаксису та обережна поведінка старих збережень.

Runner також виконує поточні 147 сценаріїв національного відновлення з `diplomacy_package_23/test_relations.py`. Старий повний `diplomacy_package_23/run_checks.py` містить історичні межі всього файлу; нові дозволені записи пари виходять за них. Його історичні журнали й лічильники не переписані, а повний старий результат не оголошується успішним. Поточний runner звіряє SHA-256 усіх спільних файлів між чотирма перевірками.

Під час першого нативного завантаження виявлено, що `has_opinion_modifier` приймає скалярний ID без `target`, а скорочені `>=`/`<=` недопустимі. Тепер точні пари зберігаються у власних прапорцях, порівняння змінних використовують документований `compare`, поріг політичних очок — `NOT = { has_political_power < 10 }`. Первинна документація встановленої гри перевіряється окремо; наявність примітива в ній сама по собі не доводить його приймання рушієм.

Кількість assertions є лічильником саме поточних запусків, не сумою історичних тестів. Перевірки не змінюють гру, лаунчер, збереження чи Workshop. Нативну компіляцію, кампанію, AI timing, збереження/завантаження нового реєстру та мультиплеєр треба підтверджувати окремо.
