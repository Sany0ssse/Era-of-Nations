Run `python -B tools/validation/diplomacy_package_11/run_checks.py` from the checkout.

The runner checks 140 new actual-source scenarios in 23 groups and the previous 5401 scenarios, for 5541 cumulative scenarios. This package adds no adapter semantics cases; independent source assertions stay separate. The ordered executor loads only package 10 definitions; historical scenario loops run and count separately. Baseline inventory supplies the 31 literal decision/state/terrorism-account mappings, while every executed policy, admission, completion, cancellation and outcome body comes from current source. Eight SHA-256 hashes identify the owned game files. Unknown source commands fail closed.

The checks cover all 31 original raid routes and all 31 new free human cancellation decisions, domestic and foreign authorization, immutable territorial owner, mutual treaty flags, original national and multi-territory filters, inactive ASALA account ARW, native NOR semantics, fresh strict command power above25, single25 debit, stale callback serialization, both annex hooks/roles and both raid-versus-CT hook orders, independent slots, orphan initialization, legacy callbacks and unrelated state preservation.

The original five-day remove callback and 35-day re-enable declaration remain. Cancellation refunds a known paid cost once and keeps the original slot reserved until that callback is consumed. Invalid authorization cancels without executing an inherited outcome. If the seven-day watchdog flag is missing before the callback arrives, forced cleanup retires only that slot permanently; the tests verify all other 30 routes remain eligible under their original national conditions. A consumed cancellation releases without retirement; scripted eligibility can reopen, while actual native re-enable timing is unproven. Unidentified legacy callbacks do not infer a refund or outcome.

Command-power and army-experience caps are explicit native primitive fixtures, separate from actual scripted debit and refund logic. The tests observe actual helper before/add/after arithmetic and verify command power plus the retained claim across full, partial, capped and negative credit. A native over-cap clip increases the claim by the observed lost amount. Annexed operators keep their claims in their original country; they do not transfer to the annexer, and release requires that country to exist again.

A deterministic named-result seam selects and executes real `random_list` branches, including all success/failure events and ordinary experience, while checking the preserved source weight formula and bounds. It does not establish native probability. Timer flags, country/state ownership, modifiers, caps and focuses are explicit facts. Native decision/callback timing, cancellation/re-enable, elapsed watchdog expiry, state/owner scope binding, cost/cap behavior, random probability, GUI, save/load and campaign remain unproven. Arbitrary duplicate callbacks from an already consumed timer into a later identical slot are outside this bounded model. These checks do not launch the game or alter saves, Workshop files or launcher playsets.
